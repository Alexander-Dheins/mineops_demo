# MineOps Manager — demo

Demo estática de MineOps Manager (gestión de operaciones mineras), hecha con Next.js y Tailwind.
No tiene backend ni funcionalidad: todas las pantallas usan datos de muestra inventados.

Pantallas: acceso (`/`), proyectos (`/proyectos`), panel del proyecto (`/proyectos/ppcha1`) y
dashboard de embarque (`/proyectos/ppcha1/embarque`).

```bash
npm install
npm run dev
```
